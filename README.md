Obiettivo
---------

L'obiettivo del progetto e' di dotare la PAT dei suoi XSD (e file corredati, es. XML, SCH) quantomeno dei procedimenti edilizi (es. PdC, SCIA) e compatibili con le regole di digitalizzazione del SSU.
